# Campaign v2

Template sets that reach bpfix's output, and padding and renaming of the upstream cases.
The cited v1.0.2 inputs in `mutants/` and `fixtures/` are untouched.

| Path | Contents | Generated by |
| --- | --- | --- |
| `mutants/RenameReject/` | 7 pairs of rejecting NullablePointer programs with an uncredited check; pair members differ in one identifier | `tools/generate_v2_mutants.py` |
| `mutants/VolatilePad/` | PBV / PBS / SRV / NPV at pads 0, 8, 32; padding survives `-O2` | same |
| `mutants/ProvenanceMap/` | PPM at pads 0, 8, 32; packet pointer round-tripped through a map value | same |
| `upstream/<case>/` | orig / pad8 / pad32 / rename variants of the 75 vendored main75 cases + `transform.json` | `tools/gen_upstream_metamorphic.py` |
| `lab/<label>-<stamp>/` | Runs on the laboratory pin (created by `lab/run_v2_campaign.sh`) | [`docs/LAB-RUN-V2.md`](../../docs/LAB-RUN-V2.md) |

`make v2-mutants` regenerates the sources. `tests/test_v2_campaign.py` checks
that they equal the committed bytes, and that the committed scores of the pin run re-derive
from its captures.
