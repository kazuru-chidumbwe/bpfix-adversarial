fix: Bound arg metadata index with an unconditional mask

clang > 20 lowers the switch over a0..a4 to a computed table load and
copies the index before its own range check. Pre-5.7 verifiers do not
propagate the narrowed range to that copy, so the load is rejected on
4.19 with:

  R2 unbounded memory access, make sure to bounds check any array
  access into a map

Index the args the same way generic_process_event() already does and
mask after the decrement, so the bound holds no matter how the check
is scheduled.

Signed-off-by: Tam Mach <tam.mach@cilium.io>
