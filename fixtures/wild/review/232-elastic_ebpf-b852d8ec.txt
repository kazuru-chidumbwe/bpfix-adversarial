fix: load clang-18 probes on kernels before 6.15 (#249)

After #248 probes built with clang-18 do not load on kernels before 6.15. 22 of 27 programs fail.
The verifier error is "invalid func unknown#195896080".
elastic/ebpfevents builds the probes with clang-18. This repository builds them with zig (LLVM 13), so our tests did not find the problem.

Fix
* Each read of an optional field has its own bpf_core_field_exists() guard.
* No guarded branch returns before the fallback read.
* PathResolver.h uses this rule for kernfs_node::parent.
* ebpf_tty_driver__is_pty_master() has the same risk. It now uses the same rule.
