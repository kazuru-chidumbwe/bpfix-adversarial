gadgets/traceloop: Unroll loop to make verifier happy

The verifier rejects the program with the "math between map_value
pointer and register with unbounded min value is not allowed" error
if the loop is not unrolled on kernel 5.4.0-136-generic on ubuntu.
(Tested also in 5.4.0-1104-azure and the same happens).
