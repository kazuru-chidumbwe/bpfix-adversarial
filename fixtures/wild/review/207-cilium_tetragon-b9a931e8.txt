fix: Ensure env read buffer size is never negative

read_args() got an explicit size check in 15d5ff634, but read_envs()
kept the same "if (envs_size) envs_size -= 1" construct. Under clang
> 20 that compiles to a register-to-register compare, so the verifier
never narrows the range and rejects the program with:

  R2 min value is negative, either use unsigned or 'var &= const'

Relates: #5453
Signed-off-by: Tam Mach <tam.mach@cilium.io>
