bpf: Only enable NAT46/64 for 5.4+ kernels

For 4.19 kernels, NAT46/64 code is generating more than 4096 insns inside
the tail_nodeport_nat_ipv6() tail called program:

  [...]
  libbpf: load bpf program failed: Argument list too long
  libbpf: Program too large (4109 insns), at most 4096 insns
  libbpf: failed to load program 'tail_nodeport_nat_ipv6'
  [...]

Thus, restrict NAT46/64 enablement only for kernels with large insn limit.

Signed-off-by: Daniel Borkmann <daniel@iogearbox.net>
