bpf: Fix misaligned access in bpf_xdp with prefilter and IPv6

When both prefilter and IPv6 are enabled, bpf_xdp fails to load with:

    51: (79) r1 = *(u64 *)(r2 +30)
    52: (7b) *(u64 *)(r10 -12) = r1
    misaligned stack access off (0x0; 0x0)+0+-12 size 8

This is caused by the memcpy call on pfx.lpm.data:

    memcpy(pfx.lpm.data, &ipv6_hdr->saddr, sizeof(pfx.addr));

This call uses our optimized memcpy implementation which requires the
destination on-stack objects to the 8-bytes aligned. Normally we would
fix it by aligning the pfx object, but here the destination buffer is
actually, pfx.lpm.data which is not at the start of pfx. We therefore
need to fallback to the unoptimized, builtin memcpy.

Fixes: 9c85721 ("bpf: optimized memcpy/memzero with dw-wide copies")
Signed-off-by: Paul Chaignon <paul@cilium.io>
