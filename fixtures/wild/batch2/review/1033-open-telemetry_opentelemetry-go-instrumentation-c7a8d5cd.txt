Remove support for Go < 1.19 instrumentation (#1815)

* Remove support for Go < 1.19 in inspect

* Regenerate offsets

* Drop check for ABI registration

context for consistent keys.

* Update COMPATIBILITY.md

* Add changelog entry

* Fix verifier error

* Remove get_consistent_key

Flatten GOROUTINE call instead.
