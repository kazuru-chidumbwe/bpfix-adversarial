Skip UDP GSO linearization in BPF unit test builds

In UNITTEST builds, clang constant-folds the ctx->globals pointer to 0
(the __globals extern base in .rodata), producing a scalar dereference
that the BPF verifier rejects. Since BPF_PROG_TEST_RUN never produces
real GSO packets, the linearization code is dead in that context.
Guard it with #ifndef UNITTEST.

Co-Authored-By: Claude Opus 4.6 <noreply@anthropic.com>
