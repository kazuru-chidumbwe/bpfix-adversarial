bpf/tests: TCP and UDP checksum checks.

All added checksums where verified in wireshark by dumping eBPF unit
tests payloads using `-dump-ctx` flag.
Checksum log fatal message type changed from decimal to hexadecimal
to make it easier for troubleshooting.

Signed-off-by: viktor-kurchenko <viktor.kurchenko@isovalent.com>
