Add kfunc:: for calling kernel functions directly (#5360)

Kernel functions can now be called from a script with a `kfunc::` prefix:

    tracepoint:syscalls:sys_enter_read {
      $t = kfunc::bpf_task_from_pid(1);
      if ($t != 0) {
        printf("pid 1 is %s\n", $t->comm);
        kfunc::bpf_task_release($t);
      }
    }

The call is emitted as a declaration in the ".ksyms" section, which is how
libbpf recognises a kfunc.

The namespace lets codegen tell a kfunc apart from a function linked in
from an imported C file.

Two compile-time checks keep the common mistakes out of the verifier log: the
name must exist in kernel BTF, and `kfunc_allowed()` must confirm it is a real
kfunc registered for the probe's program type.
