aya-obj: fix flexible array relocations

CO-RE bounds checking compared the requested array element index with
the parent struct's member count. This rejected nonzero indices in
trailing zero-length arrays and could accept an access to a non-final
zero-length array by coincidence.

Use the containing member's position to identify flexible arrays in
both local and target layouts. Retain bounds checking for fixed-size
arrays and non-final zero-length arrays.

Exercise compiler-emitted CO-RE relocations across different source
and target layouts, checking the offset produced by the running BPF
program. Reject invalid local accesses and verify field-existence
relocations return false for elements outside target array bounds.
Seed the output map so zero-valued results require program execution.

Fixes: #1662
Co-authored-by: Matteo Porta <matteo.porta@sysdig.com>
