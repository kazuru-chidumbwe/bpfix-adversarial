[USM] Support redis PING command (#42120)

### What does this PR do?

 This PR adds support for monitoring Redis PING commands in Universal Service Monitoring (USM). Previously, only GET and SET commands were tracked. This change enables:

  - Detection and tracking of Redis PING commands in both TCP and TLS connections
  - Support for both RESP2 and RESP3 protocol versions (Redis 1.2+ and 6.0+)

### Motivation

  Redis PING commands are commonly used for:
  - Health checks and connection keep-alives
  - Latency measurements
  - Connection validation in connection pools

### Describe how you validated your changes

Testing:
  - Added comprehensive test coverage in redis_monitor_test.go:
    - PING with RESP2 protocol (simple string response: +PONG\r\n)
    - PING with RESP3 protocol (supports null, boolean, and other new types)
    - PING with message parameter (returns bulk string instead of simple string)
    - Tests with and without resource tracking enabled
    - Tests for both TLS and non-TLS connections

### Additional Notes

The issue was tested on the staging environment to verify the support.
