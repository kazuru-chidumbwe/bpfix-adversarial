feat(iolatency): collect block IO latency and size intervals

Collect Q2G, Q2D and D2C latency and IO size intervals for SCSI, NVMe and
virtio disks. Check iostats and request-time accounting once at startup,
treating nonzero iostats values as enabled.

Read Q from the bio's kernel submission timestamp and G/last D from the
request. Support packed and full-width bio timestamps by field presence.
Missing Q skips only Q2G/Q2D; D2C and size accounting stay independent.
Keep kernel timestamp precision, including plug caching and merging.
Nonpositive Q-stage deltas enter the first bucket without an exact timing
guarantee; missing times and reversed D2C remain invalid.

Q records queued size. Bio remap supplies it only when the kernel's
completion flag suppresses a later Q, excluding partition translation.
Request remap accounts directly dispatched clones. Resolve the actual bio
flag enum, retaining the legacy macro ABI when no enum exists.

Raw request completion settles whole bios within its completed byte range.
Partial bios wait for their later completion. Bound walks to 512 bios, keep
classification and container updates in scalar helpers, and arrange
optional exits so older verifiers can bound the walk. Inline counter
lookup/create to avoid an extra active verifier call frame, without adding
map lookups, field reads or accounting work. No per-bio state needs
retention or reclamation, including IO that ends before forming a request.

Probe disk identity under a sysfs-owned reference, then publish Host
counters from the sole userspace creator. Keep the cold sysfs probe with
the session; its result map is empty after startup. Device changes discard
the session and its baselines, including a change observed after capture:
reject that interval before publishing it. Unsupported online configuration
changes do not introduce disk pause or re-enrollment states.

Use each live bio's CSS and cache its kernel serial until final release.
Publish release in the counter stream so userspace can reclaim that
generation. Compute raw deltas before combining public container labels.
Read failures rebuild the baseline; attribution failure preserves Host.

NVMe and virtio size samples use the wide completion byte count. SCSI uses
its last-dispatch sector count across partial completions, including the
older request_aux layout. Keep its 16-bit sector capacity instead of adding
request-size state or a dispatch probe.

Define shared counter layouts, keys, stage and failure values in an ABI
header and generate the Go decoding types. Preserve wire values, offsets,
bucket bounds and map capacities. Native C fixtures consume the same header
while retaining independent accounting and layout checks.

Select raw tracepoint arguments with attach-time capability probes. Require
selected hooks and check initialized software crypto fallback before
publishing the session.

Copy adjacent bio/request fields in CO-RE-checked snapshots. Other layouts
keep the individual field reads.

The complete series versus main averaged the following IOPS with Huatuo
enabled. Both versions pinned a single fio process to the same CPU in the
NVMe PCI device's NUMA node, using 4 KiB random reads at QD 256:

  Kernel  Main     This series  Gain
  4.18    155,721  215,063      38.11%
  5.10    239,532  277,294      15.76%

Each version had five alternating 15-second runs after two seconds of
warmup, with BPF runtime statistics disabled.

For performance comparisons, pin fio to a CPU in the NVMe PCI device's NUMA
node and keep the submission CPU fixed across versions.

+ * Inspect initialized software encryption at startup.
+ * The running kernel's enum supplies the full tfms_inited array length.
+ * Byte-sized reads work with the legacy probe-read helper and preserve its
+ * error result; a failed read never means that encryption is unused.

+struct {
+	__uint(type, BPF_MAP_TYPE_ARRAY);
+	__uint(max_entries, 1);
+	__type(key, __u32);
+	__type(value, __s64);
+} io_latency_crypto_map SEC(".maps");
+
+SEC("raw_tracepoint/sys_enter")
+int probe_crypto_fallback(struct bpf_raw_tracepoint_args *ctx)
+{
+	__u32 key = 0;
+	__s64 *result = bpf_map_lookup_elem(&io_latency_crypto_map, &key);
+	__s64 completed = IO_LATENCY_CRYPTO_UNUSED;
+	int i;
+
+	if (!result || *result)
+		return 0;
+
+#pragma unroll
+	for (i = 0; i < IO_LATENCY_CRYPTO_MODE_CAPACITY; i++) {
+		__u8 initialized = 0;
+		int ret;
+
+		if (i >= io_latency_crypto_modes)
+			break;
+		ret = (int)bpf_probe_read(&initialized, sizeof(initialized),
+					 (const void *)(io_latency_tfms_inited + i));
+		if (ret) {
+			completed = ret;
+			break;
+		}
+		if (initialized)
+			completed = IO_LATENCY_CRYPTO_INITIALIZED;
+	}
+	/* Publish one complete observation in a single aligned 64-bit value. */
+	*result = completed;
+	return 0;
+}
