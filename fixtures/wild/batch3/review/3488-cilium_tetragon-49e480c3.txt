tetragon: Use bpf_for in match_cmd_args function

Use bpf_for in match_cmd_args function to save some verifier cycles
on recent kernels. This affects generic_uprobe_process_filter program:

File                      Program                            Insns (A)  Insns (B)  Insns     (DIFF)
------------------------  ---------------------------------  ---------  ---------  ----------------
bpf_generic_uprobe_v61.o  generic_uprobe_process_filter         205567     164076  -41491 (-20.18%)

States (A)  States (B)  States   (DIFF)  Program size (A)  Program size (B)  Program size (DIFF)
----------  ----------  ---------------  ----------------  ----------------  -------------------
      8815        6805  -2010 (-22.80%)              4666              4754         +88 (+1.89%)

Note by doing the negative case first 'if (!CONFIG(ITER_NUM)))' we save
4k more verifier instructions, not sure why.. but oh well.
