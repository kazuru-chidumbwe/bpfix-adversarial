tetragon: Add USE_PERF_RING_BUF config variable

We allow to use perf ring buffer based on --use-perf-ring-buffer config
option. We store that bool value in struct tetragon_conf and bpf program
uses ring buffer based on that.

This value will never change within the tetragon instance execution, it's
better to add it as frozen/read-only config value, so verifier can remove
unused ring buffer code from bpf sensors.

Signed-off-by: Jiri Olsa <jolsa@kernel.org>
