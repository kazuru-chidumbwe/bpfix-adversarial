stdlib: add str_concat() to concatenate two strings (#5265)

Concatenate two strings into a new string, example:

    $new = str_concat("hello", " world");
    $new = str_concat($new, "!!!");
    $new = str_concat("INFO: ", $new);

    printf("%s\n", $new);

    INFO: hello world!!!

To allow the external interface function __bpf_strnlen to be called
by other functions in strings.bpf.c and to solve the problem of
`The sequence of xxxx jumps is too complex`, a bpf_loop is used
instead of a for loop.

__bpf_str_concat(), the verifier will complain about the following error
