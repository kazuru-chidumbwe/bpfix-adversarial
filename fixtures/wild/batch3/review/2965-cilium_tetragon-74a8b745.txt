tetragon: Add kprobe support to retrieve register as data

Adding support to retrieve register as data via "pt_regs" source.
ATM it's supported only for x86 kprobes and uprobes.

Following example retrieves eax register (4 bytes) as data:

  data:
  - index: 0
    type: "int"
    source: "pt_regs"
    resolve: "eax"

I had to move the process_call_heap lookup directly to the read_arg,
because it got mangled with all the nesting and verifier complained
about its pointer arithmetic.

Reading syscall registers is special due to syscall wrapper used on some
architectures with ARCH_HAS_SYSCALL_WRAPPER enabled. Here we have context
data stored in memory so we need to use probe_read helper for that.

Signed-off-by: Jiri Olsa <jolsa@kernel.org>

+FUNC_INLINE long get_pt_regs_arg_syscall(struct pt_regs *ctx, __u16 offset, __u8 shift)
+{
+	void *_ctx;
+	long val;
+
+	_ctx = PT_REGS_SYSCALL_REGS(ctx);
+	if (!_ctx)
+		return 0;
+
+	probe_read(&val, sizeof(val), _ctx + offset);
+	val <<= shift;
+	val >>= shift;
+	return val;
+}
