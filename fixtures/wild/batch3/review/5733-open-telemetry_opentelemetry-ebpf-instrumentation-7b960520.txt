Honor context propagation modes in Go clients (#3011)

* Honor Go header propagation modes

Separate the kernel write-user capability from configured HTTP header
propagation. Disabled and tcp modes no longer inject traceparent values.

Keep Go Auto SDK activation capability-gated under the default disabled
mode, and cover the public mode contract with unit and wire-level tests.

* Preserve Go wire propagation without write helper

Keep header-mode correlation active when kernels cannot expose the
bpf_probe_write_user helper so tpinjector can still mutate plaintext
traffic on the wire.

Gate only the in-process HTTP and gRPC buffer writers on helper support,
and cover both the verifier configuration and unaffected manual spans.

* Inline Go write-user capability check

Remove the single-use temporary from gotracer constant construction. The
map now reads the capability directly without changing the configured BPF
value.
