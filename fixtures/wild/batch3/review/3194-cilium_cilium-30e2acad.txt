bpf, socketlb: move MKE enablement to runtime config

Use a non-zero MKE host class ID to enable the MKE host-network
extension, removing the ENABLE_MKE compile-time macro.

Populate the class ID only when MKE and kube-proxy replacement are
enabled, preserving the existing behavior. Extend the verifier
permutations to cover the enabled datapath path.
