fix(ebpf): live-H fallback in bpf_h_extract closes OpenSSL cold-start race (#262)

* fix(ebpf): live-H fallback in bpf_h_extract closes OpenSSL cold-start race

On the libcrypto-hook H-extraction path (OpenSSL 3.2+), bpf_h_extract gated
the rewrite on an evp_h_cache hit. The cache is populated only by the
EVP_CipherInit_ex uretprobe, which fires once during the TLS handshake. If
kloak attached that uretprobe after the app's handshake (an inherent race
between async pod-detect→attach and the app's first HTTPS request), the
cache stayed empty for that connection's enc_ctx. Because a keep-alive
connection reuses one enc_ctx set up once at handshake, every subsequent
SSL_write missed the cache and the secret was never rewritten — the write
went out unmodified, forever, for that connection.

This surfaced as intermittent e2e failures concentrated on the OpenSSL
3.5.x / 4-hop demos (python, js, raw-tls, cipher 4hop) while the Go path
and OpenSSL 3.0 3-hop path passed: when kloak won the race it worked and
was fast; when it lost, the rewrite never happened and the test waited out
its readiness window.

Fix: on cache miss, derive H live from the same enc_ctx → algctx → H chain
the uretprobe and the kprobe-walk fallback already use (we already hold
enc_ctx), then backfill the cache for the fast path. The cache becomes a
pure optimisation rather than a correctness dependency. As a bonus this
also handles TLS 1.3 KeyUpdate rekeys that a one-shot cache would miss.

Adds DBG_H_EXTRACT_LIVE_WALK so the fallback's hit rate is observable.

* fix(ebpf): address review — aligned H buffer, drop double counter

Per Gemini review on #262:
- Back ghash_h with a __u64[2] so the zero-check and bswap operate on an
  8-byte-aligned buffer (avoids strict-alignment/verifier issues from
  casting an under-aligned __u8[16] to __u64*).
- Remove the trailing unconditional DBG_H_EXTRACT_CACHE_HIT increment: the
  counter is now bumped in the cache-hit branch, and the live-walk path is
  counted by DBG_H_EXTRACT_LIVE_WALK, so the tail increment double-counted
  hits and mislabelled live walks.
