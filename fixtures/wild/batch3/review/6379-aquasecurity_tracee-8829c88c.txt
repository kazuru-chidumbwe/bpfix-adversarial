fix(ebpf): optimize programs size via bounds tracking

Reduce programs size by ~13.5 KB and object file size by ~40.5 KB
across 8 programs through better register bounds tracking in
save_bytes_to_buf_max. This optimization was required to make objects
generated by clang19 pass verification on older eBPF verifiers
(kernel <= 5.10). Uses local variables and update_min() to maintain
verifier bounds without redundant checks.

Program size reductions:
- kprobe/security_task_prctl: -160 bytes
- uprobe/lkm_seeker: -3168 bytes
- uprobe/lkm_seeker_kset_tail: -3312 bytes
- uprobe/lkm_seeker_modtree_loop_tail: -3168 bytes
- uprobe/lkm_seeker_new_mod_only_tail: -144 bytes
- uprobe/lkm_seeker_proc_tail: -3368 bytes
- uprobe/lkm_seeker_submitter: -112 bytes
- uprobe/trigger_mem_dump_event: -56 bytes

Maintains compatibility with older eBPF verifiers (kernel <= 5.10).
