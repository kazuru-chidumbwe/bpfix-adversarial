fix: validate DNS TTL on dns_ip_map lookups (#46) (#51)

Add dns_entry_expired() check at all three dns_ip_map lookup sites:
- tp_exit_connect: skip expired entries when verifying connections
- resolve_host (cached fd path): skip expired hostname mappings
- resolve_host (fd scan path): skip expired hostname mappings

Expired entries are skipped (not deleted) — the LRU will evict them
and the next DNS response will refresh. TTL of 0 means never expires.

Without this fix, stale DNS entries persisted until LRU eviction,
allowing expired IP→hostname mappings to pass the host filter even
after the DNS TTL expired and the IP was reassigned.

Fixes #46

+// Check if a dns_ip_map entry has expired based on its TTL.
+// Returns 1 if expired, 0 if still valid. TTL of 0 means never expires.
+static __always_inline int dns_entry_expired(struct dns_ip_val *div) {
+  if (div->ttl_sec == 0)
+    return 0;
+  __u64 age_ns = bpf_ktime_get_ns() - div->inserted_at;
+  __u64 ttl_ns = (__u64)div->ttl_sec * 1000000000ULL;
+  return age_ns > ttl_ns;
+}
