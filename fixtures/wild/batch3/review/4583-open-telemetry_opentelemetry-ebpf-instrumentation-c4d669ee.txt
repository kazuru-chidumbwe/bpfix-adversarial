Activate Go Auto SDK instrumentation (#2810)

* Activate Go Auto SDK instrumentation

Attach an optional Go probe group that activates the OpenTelemetry Auto
SDK only when required symbols, offsets, and user-memory writes are safe.
Roll back the group atomically when activation cannot be supported.

Track provisional span lifecycle state until the SDK context is committed.
Restore nested contexts before emitting the bounded rich event so malformed
or oversized payloads cannot leave process state behind.

Gate activation on conservative module and ABI checks, and exercise both
ends of the supported OpenTelemetry range with integration fixtures.

* Track the rolling Auto SDK fixture

Keep the lower OpenTelemetry compatibility lane pinned at v1.33 while
renaming the upper lane to latest and allowing Renovate to advance its
OpenTelemetry dependencies through patch and minor releases.

Allow the existing synthetic fallback for oversized payloads while
continuing to reject rich spans that contain the oversized attribute.

* Scope Auto SDK activation probes by process

Attach the write-capable newSpan uprobe only to the target process and
retire it after a matching PID and generation acknowledgement. Keep the
lifecycle probes executable-scoped so completion and cleanup remain
isolated across processes sharing an executable.

Route activation acknowledgements through the shared ring-buffer context
and validate process plus executable identity before attachment. This
prevents stale PID generations and cross-device inode collisions from
redirecting the temporary write-capable probe.

* Normalize Auto SDK executable identity

Darwin exposes syscall.Stat_t.Dev as int32, while OBI stores device and
inode identities as uint64. Normalize both stat fields before comparing
them so macOS lint can compile the activation path.

* Document Darwin device conversion

Keep the device normalization required by Darwin while suppressing the
Linux-only unconvert diagnostic. Leave the inode comparison in its native
portable type.

* Normalize device IDs portably

Handle the different Stat_t.Dev types used by Linux and Darwin without
platform-specific lint suppressions. This keeps executable identity checks
consistent across supported development hosts.

* Align Auto SDK probe registration

Pass executable device and inode values through the merged optional-probe
orchestrator so the Go tracer satisfies its process-scoped interface. This
allows the activation probe group to register after instrumentation.

* Verify page-boundary propagation end to end

The integration test previously depended on a BPF debug message that can be
dropped while the allocation search emits a burst of probe logs. The resulting
trace already verifies that context injection and parent-child propagation
succeed for the page-aligned span, so use those observable results alone.

+SEC("uprobe/tracer_new_span")
+int obi_uprobe_tracer_NewSpan(struct pt_regs *ctx) {
+    u64 generation = 0;
+    if (!go_auto_target_generation(&generation) || !g_bpf_header_propagation ||
+        !span_context_offsets_available()) {
+        return 0;
+    }
+
+    bool *auto_span_ptr = GO_PARAM4(ctx);
+    if (!auto_span_ptr) {
+        return 0;
+    }
+
+    bool auto_span = false;
+    if (bpf_probe_read_user(&auto_span, sizeof(auto_span), auto_span_ptr) != 0) {
+        return 0;
+    }
+    if (auto_span) {
+        notify_go_auto_activation(generation);
+        return 0;
+    }
+
+    go_auto_activation_attempt_key_t attempt_key = {};
+    if (!reserve_go_auto_activation_attempt(generation, &attempt_key)) {
+        return 0;
+    }
+    if (!go_auto_target_matches(generation)) {
+        bpf_map_delete_elem(&go_auto_activation_attempts, &attempt_key);
+        return 0;
+    }
+
+    const bool activate = true;
+    if (bpf_probe_write_user(auto_span_ptr, &activate, sizeof(activate)) != 0) {
+        bpf_dbg_printk("failed to activate Go Auto SDK");
+    } else {
+        notify_go_auto_activation(generation);
+    }
+
+    return 0;
+}
