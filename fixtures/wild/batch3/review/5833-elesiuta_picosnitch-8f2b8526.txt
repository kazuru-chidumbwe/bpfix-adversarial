Track grandparent process

Adds end-to-end grandparent process tracking. The BPF program walks
task->parent->parent and records gpcomm/gpino/gpdev/gppid alongside
the existing parent fields in exec, sendrecv4 and sendrecv6 events.
The userspace pipeline (monitor → primary → secondary) extends the
parent walk from 2 to 3 levels, resolving each process's exe via the
existing dev/ino fd cache and inode fallback.

The connections table gains a gpexe_id FK to executables, plus
covering indices idx_pexe_id_contime and idx_gpexe_id_contime so the
TUI/web grandparent group-bys are fast.

State (state.json) gains 'Grandparent Executables' and
'Grandparent Names' for first-seen notifications. New tests:
TestGrandparentTracking verifies the gpexe_id column exists and that
a forked shell→curl chain resolves the grandparent correctly.
