* feat: per-destination circular buffer for tc_pending

Replace the single-entry tc_pending map with a per-destination FIFO
queue (depth 4). This prevents rapid SSL_writes from overwriting each
other's patches before tc egress processes them.

Two LRU maps replace the old hash map:
- tc_queue_meta: dst_ip → {head, tail} queue state
- tc_pending: {dst_ip, slot} → queue entry

The uprobe enqueues at tail, tc dequeues from head. If the queue is
full, the oldest entry is dropped. LRU eviction handles stale entries
from abandoned connections.

* fix: defer H extraction to kprobe, active-flag consume

Two fixes for reliability:

1. Move H extraction from uprobe (SSL_write entry) to kprobe
   (tcp_sendmsg). At SSL_write entry, the TLS handshake hasn't
   completed yet for new connections — the encryption context has
   NULL pointers. By tcp_sendmsg time, the handshake is done and H

   created entries for the next request on keep-alive connections.
   With active=0, retransmits find the entry but skip it.

* feat: TLS 1.3 support via plaintext_len-based version detection

Detect TLS version per-connection by comparing record_len with the
known plaintext_len from the SSL_write call:
  TLS 1.2: record_len = plaintext_len + 24 (8 nonce + 16 tag)
  TLS 1.3: record_len = plaintext_len + 17 (1 content_type + 16 tag)

This sets nonce_len correctly (8 for TLS 1.2, 0 for TLS 1.3) without
needing to read the SSL struct version field or add new offsets.

The plaintext_len flows through the pipeline:
  uprobe (SSL_write num param) → xor_pending → kprobe → tc_pending → tc

  TLS 1.3 + TLS_AES_128_GCM_SHA256: both headers rewritten ✓
  TLS 1.2 + ECDHE_ECDSA_AES128_GCM_SHA256: both headers rewritten ✓

+// Multiply two 128-bit elements in GF(2^128) using the GHASH bit convention.
+// result = a * b in GF(2^128) with reduction polynomial x^128 + x^7 + x^2 + x + 1.
+HELPER_INLINE void gf128_mul(const __u8 a[16], const __u8 b[16], __u8 result[16]) {
+  __u8 v[16], z[16];
+  int i, j;
+
+  __builtin_memset(z, 0, 16);
+  __builtin_memcpy(v, b, 16);
+
+  for (i = 0; i < 128; i++) {
+    // If bit i of a is set (MSB-first: bit 0 is the MSB of byte 0)
+    if (a[i / 8] & ((__u8)0x80 >> (i % 8))) {
+      for (j = 0; j < 16; j++)
+        z[j] ^= v[j];
+    }
+    // Right-shift v by 1 bit (MSB-first convention)

+    for (j = 15; j > 0; j--)
