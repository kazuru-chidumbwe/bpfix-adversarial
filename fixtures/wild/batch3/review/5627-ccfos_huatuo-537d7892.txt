refactor(profiler): unify Value field in profiler_event_base_t

Move the 'value' field from mem_event_t-specific location to the common
profiler_event_base_t, making it truly universal across all profiler types.

Changes:

BPF side:
- Add s64 value to profiler_event_base_t
- Set base.value = 1 in CPU profiler (each sample counts as 1)
- Set base.value in Memory profilers (page/byte deltas)
- Remove duplicate Value field from mem_event_t
- Update all field accesses to use base.value

Go side:
- Add Value int64 to ProfilerEventBase struct
- Remove Value field from memEvent struct
- Update getValue callbacks to use base.Value via pointer conversion
- Add unsafe import to CPU and Memory profiler files

Benefits:
- Truly unified event structure across all profilers
- Simpler code: Value is always in the same location
- Reduced duplication: no need for separate value handling
- Memory layout verified: 40/72/48 bytes (base/cpu/mem)

This completes the unification of common fields across profiler types.
All events now share the exact same base structure with consistent
field offsets for unified processing.
