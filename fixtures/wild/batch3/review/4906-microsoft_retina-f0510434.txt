fix(conntrack): remove closing tcp connections from conntrack gracefully (#1438)

# Description

Before, conntrack will immediately delete a connection from its map
whenever we see the `FIN` flag, which is problematic for connections
that got closed from server-side. This PR fixes that by take into
account the 4-way teardown process. Also refactored some code to make it
more readable.
## Related Issue
Closes #1417
