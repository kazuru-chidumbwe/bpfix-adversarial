fix: reduce BPF verifier complexity for kernel 6.x (#249)

- Mark process_data as __noinline to prevent inlining at each call site
- Reduce LOOP_LIMIT from 100 to 64 to decrease verifier path explosion

Fixes BPF program loading on kernel 6.14+ where the verifier hits the
1M instruction complexity limit when tracing all possible paths.
