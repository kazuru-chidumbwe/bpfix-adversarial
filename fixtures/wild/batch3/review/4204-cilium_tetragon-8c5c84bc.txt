bpf: port cilium/cilium's optimized mem operations

For details see
https://github.com/cilium/cilium/commit/9c85721783447e10e359f723a1ee7d465c704ccc

This is almost a byte-identical copy with the addition of a comment that
disables clang-format so that the files stay more similar between the
trees.

The next commit adds some changes to the builtins.h file to make the
programs load under old kernels again.

Also use those mem operations everywhere we can. We have some places
where the size is over 128, so we have to explicitly fallback to the
compiler builtin.

To get this past the v5.4 verifier, an additional change to args_off()
was needed, which adds the offset addition to the asm instructions.
This way the compiler cannot do things that are too clever for the
verifier like placing the addition of the offset far away from the masking.
