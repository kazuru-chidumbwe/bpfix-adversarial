[CORE-11385] ebpf: add support for NATOutgoingExclusions

Add support for the NATOutgoingExclusions field from FelixConfiguration
to the ebpf dataplane. When set to IPPoolsAndHostIPs, the config is
propagated through to the bpf endpoint manager into a CALI_GLOBALS_NATOUTGOING_EXCLUDE_HOSTS global flag, which when set
exclude hosts from being SNAT'ed.

Also add a TestNATOutExcludeHosts() ut to verify this.

NATOutgoingExclusions was added, along with iptables/nftables
dataplanes support, on
https://github.com/projectcalico/calico/pull/8961. This PR adds the
ebpf dataplane equivalent support.
