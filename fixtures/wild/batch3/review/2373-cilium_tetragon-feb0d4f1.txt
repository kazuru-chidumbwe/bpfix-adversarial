bpf: reduce complexity in pfilter.h

In a previous version of the PR this commit belongs to, we needed to
decrease the complexity, especially for v511 eBPF objects.
This commit is the result.

We always mask the `index` variable before we use it to look things up
in out filter already. This commit adds additional masking after we
changed the variable so that the range the verifier needs to track is
also bounded on all operations of this variable not only when it's used
as lookup index.

Before this commit, on a 6.17 kernel with ITER_NUM=0.
